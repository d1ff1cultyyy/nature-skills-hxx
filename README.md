# Nature Skills — Claude 插件市场

本目录是 [nature-skills](https://github.com/Yuan1z0825/nature-skills)（Apache-2.0）
的 Claude 插件市场转换版：在仓库原有内容基础上补充了 `.claude-plugin/marketplace.json`
与 `plugins/nature-skills/.claude-plugin/plugin.json`，其余技能文件与上游一致。

安装：Claude Desktop 设置 → Plugins → Add marketplace → 指向本文件夹（或将其
放入任意 Git 仓库后以 owner/repo 形式添加），然后安装 nature-skills 插件。

包含 24 个技能：nature-writing、nature-polishing、nature-reviewer、nature-response、
nature-reader、nature-paper-card、nature-paper-trans、nature-paper2ppt、
nature-image2ppt、nature-paper2word、nature-paper-xray、nature-paper-to-patent、
nature-figure、nature-citation、nature-ref-verifier、nature-downloader、
nature-literature-pipeline、nature-academic-search、nature-experiment-log、
nature-data、nature-statistics、nature-social-science、nature-proposal-writer、
nature-shared（共享参考包，被其他技能引用）。
